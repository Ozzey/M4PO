# Assets

- `architectures/`: the project architecture diagram.
- `results/`: unchanged figures supplied with the M4PO manuscript.
- `videos/sim/`: unchanged supplementary simulation videos.
- `videos/gifs/`: looping video excerpts embedded in the project README.
- `videos/previews/`: retained static representative frames.

See [result and media provenance](../docs/PAPER_RESULTS.md) for sources,
manuscript-version caveats, and the distinction from current training results.

Simulator assets and robot descriptions belong to the external environment
packages rather than this documentation directory.
